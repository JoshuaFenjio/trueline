# SalaryRadar corpus diagnostic — 2026-09-20

Read-only measurement pass. No data was modified, no migration run, no scraper triggered. This file is the only artifact created.

## Methodology & caveats

- **No direct SQL/RPC access** to this Supabase instance (no `DATABASE_URL`, no `exec_sql`). Every number was computed by fetching the **entire `job_postings` table** via PostgREST (31,119 rows) and applying the site's own resolvers (`resolvePlace`, `annualMidpointEur`, `levelBucket`, `isTrainee`) and the pipeline's `classify_role`. Each `<details>` block gives the **equivalent, auditable SQL** for the Postgres table; app-normalized metrics (EUR conversion, plausibility gate, place/level resolution) are annotated as such.
- **Definitions.** *salaried* = `salary_source <> 'none'` (a figure was disclosed; includes distrusted `parsed_suspect`). *usable / median-eligible* (`n` in gates and medians) = disclosed **and** EMEA currency **and** passes the period-aware plausibility gate **and** non-trainee. Medians/percentiles are annualised-EUR midpoints (≈ `percentile_cont() WITHIN GROUP (ORDER BY annual_eur)`).
- All figures are **full-corpus, not sampled**. The Landing.jobs anonymised-employer sentinel is excluded from company counts.

## 7. Summary

1. Corpus: **31,119** postings ever, **19,870** active; **10,048** salaried — the 10k salaried milestone is **already crossed**.
2. Overall disclosure is **32.3%**; run-rate is **~1,693 new salaried points/month**, putting 30k about **12 months** out unchanged.
3. **Largest untapped source already inside the database: the `Other` bucket — 1,814 salaried postings (18.1% of all salaried data) that are real disclosed pay with no role family.**
4. Modifiers are a red herring: stripping them reclassifies only **10** titles. The fix is **new role keywords/families**, not normalisation — top-300 analysis flags **32** recurring clusters that warrant new families.
5. Geographic gate coverage: **19** countries and **44** of the top-60 cities clear n≥8; **23** countries sit below the gate.
6. Page supply: role×country **140/521**, role×city **66/923**, company **154/1721** clear n≥8; **344** more pages publish if the corpus doubles.
7. Quality is clean: **0** active non-EMEA rows, **95** width-gate failures — both negligible against 10,048 salaried.
8. **1,386** salaried rows resolve to no country and **1,418** carry a non-EMEA currency — excluded from medians but recoverable metadata, not loss.
9. **Largest source outside the database: the permitted-but-key-gated official feeds already scaffolded — France Travail, Adzuna, Reed, ITJobs.pt** — each adds structured salaried rows on an API key alone, no new engineering.
10. One move dominates ROI: **reclassifying the 1,814 stranded `Other` salaried rows** turns already-collected data into published benchmarks at zero new scraping cost.
